# Desafios Target Systems

Este diretório reúne as soluções desenvolvidas para os desafios técnicos propostos pela **Target Systems** durante o processo seletivo.

Os três desafios foram desenvolvidos em **C# com .NET**, utilizando aplicações de console e arquivos JSON quando necessário.

## Desafios

### Desafio 1 — Cálculo de comissão

Nesse desafio foi desenvolvida uma solução para calcular as comissões de vendedores a partir das vendas realizadas. A aplicação lê os dados das vendas, aplica diferentes percentuais de comissão de acordo com o valor de cada venda e apresenta os resultados agrupados por vendedor.

### Desafio 2 — Movimentação de estoque

Criação de uma aplicação para controle de movimentações de estoque, permitindo registrar entradas e saídas de produtos e atualizar as quantidades disponíveis. A solução também mantém o histórico das movimentações, registrando informações como produto, quantidade, tipo e descrição.

### Desafio 3 — Cálculo de multa por atraso

Neste desafio foi desenvolvida uma aplicação para calcular o valor de uma multa sobre documentos em atraso. O usuário informa o valor e a data de vencimento, e a aplicação calcula os dias de atraso, aplica a taxa de 2,5% ao dia e apresenta o valor da multa e o total atualizado.

## Tecnologias
